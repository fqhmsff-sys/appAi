# Pelon Pidex — Group UI refinement

- 5 original custom-AI logo marks, each with one accent color and a clean Pelon-style visual language.
- Animated identity marker beside AI messages instead of a background character.
- @mention support for Pelon and every custom AI.
- WhatsApp-style reply/quote interaction for group messages.
- Reply preview appears above the composer and quoted context is preserved in the sent message.
- Group messages remain independent outputs; the UI does not merge AI replies into one answer.
- Reduced-motion support for agent animations.

The actual AI provider execution remains dependent on the group gateway/provider configuration.
