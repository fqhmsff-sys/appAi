# Pelon Pidex V21 — Group Character UI

- Group UI refined to match the clean Pelon product language.
- Custom AI identities use character-face SVGs with visible eyes and expressions, not generic flat symbols.
- Five character choices remain visually distinct; each uses a single primary accent color.
- Pelon uses the existing Pelon character mark.
- Group header uses a compact stacked character identity.
- AI message avatars support animation intents: idle, thinking, typing, answering, reading, surprised, and focused.
- Animation is rendered beside the message/avatar and is not a page background animation.
- Existing group features remain: separate AI messages, @mentions, replies/quotes, local persistence, and group gateway integration.
