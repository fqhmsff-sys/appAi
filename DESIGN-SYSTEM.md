# Pelon Design System V1

## Identity

Pelon is monochrome by default.

Do not introduce generic AI-app blue or orange accents into the core brand.

## Typography

Primary UI typeface:
Inter

Brand wordmark:
A clean geometric sans treatment with generous spacing and a strong lowercase-friendly rhythm.

Recommended CSS fallback:
Inter, ui-sans-serif, -apple-system, BlinkMacSystemFont, "Segoe UI", sans-serif

## Iconography

All interface icons must be SVG.

Do not use emoji, Unicode pictograms, decorative bullets, check symbols, degree symbols, or text characters as icon replacements.

Icons should be:
- simple
- consistent in stroke weight
- rounded
- visually quiet
- aligned to the surrounding text

## Logo

Use the supplied Pelon mark asset.

Do not rasterize the logo unnecessarily.

The logo must remain sharp at all display sizes.

## UI direction

The product should feel:
- premium
- calm
- precise
- modern
- original
- highly readable

Avoid:
- neon
- cyberpunk
- excessive gradients
- generic blue AI branding
- generic orange AI branding
- excessive glass effects
- decorative visual noise


## Brand ownership

Pelon is created by Qih.

The logo is intentionally independent from the generic blue/orange visual language commonly seen in AI products. In dark mode, the Pelon mark switches to a white monochrome treatment while retaining the same geometry.


## Typography modes

Pelon has two user-selectable typography modes:
- Default: clean modern system typography.
- Comic: a playful comic-style fallback available as an alternative.

The selected typography is stored locally on the device.
