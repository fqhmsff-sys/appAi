# Pidex V4

Perubahan utama:

- Identitas logo Pidex baru dengan unsur coding sederhana, tetap satu bahasa visual dengan Pelon.
- Tema terang/gelap dipindahkan ke Pengaturan.
- Tentang Pelon dipindahkan ke Pengaturan.
- Tentang Pelon menyebutkan bahwa Pelon dibuat oleh Qih.
- Pidex sekarang memakai shell miliknya sendiri bernama Pish (Pidex Shell).
- Pish adalah shell internal yang dirancang khusus untuk workspace Pidex.
- Pish memiliki command file/folder, editor, project, diagnostics, preview, utility, history, dan doctor.
- Preview mempunyai URL bar lokal dan tombol Tutup.
- Preview dapat dibuat layar penuh dan ditutup kembali dengan tombol atau Escape.
- Preview hanya menampilkan hasil kode di dalam frame sandbox.
- Shortcut Ctrl/Cmd utama di editor dibuat aktif, termasuk A, C, V, X, Z, Y, S, F, H, N, Shift+N, U, P, B, ` dan Enter.
- Syntax highlighting diperluas dengan beberapa kelas warna untuk keyword, string, comment, number, operator, tag, attribute, builtin, dan function.
- Nomor baris dipisahkan dari area kode sehingga tidak menimpa teks.
- Runtime browser langsung diperluas untuk JavaScript, HTML, CSS, Python, TypeScript, SQL, Lua, Markdown, serta preview data/text seperti JSON, XML, YAML, TOML, INI, dan GraphQL.
- Bahasa lain tetap terdaftar di Pidex dan dapat dihubungkan ke runner sandbox/wasm berikutnya.
- Background Pidex menggunakan motif kode yang sangat samar dan bergerak perlahan agar tidak mengganggu keterbacaan.
